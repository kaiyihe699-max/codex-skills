# 传感器分析

## 两类结果

### 直接测量

以下字段直接来自 RAW mosaic 与相机黑白电平：

- 每个 CFA 通道的黑电平和白电平
- P1、P50、P99、P99.5、P99.9 分位数
- 大于归一化 0.98 的近裁切比例
- 大于归一化 0.995 的裁切比例
- 小于归一化 0.01 的深暗部比例

归一化公式：

```text
normalized = (raw_value - channel_black) / (channel_white - channel_black)
```

统计前按 CFA 颜色索引使用对应通道电平，不要用单一黑电平处理所有像素。

大图抽样步长必须与 CFA 周期互质，避免偶数步长只命中 Bayer 的一个颜色相位。报告同时记录请求步长和实际安全步长。

### 估算

以下结论依赖阈值与场景分布：

- `estimated_highlight_headroom_stops`
- `suggested_base_exposure_ev`
- 阴影可恢复性
- 高光重建是否自然

报告必须把它们写成估算或建议，不写成相机动态范围测试结果。

## 高光

- `near_clip_fraction`：接近白电平，仍可能有少量余量。
- `clipped_fraction`：已经贴近或达到通道白电平。
- 橙色地图：局部只有一到两个 CFA 通道接近饱和，可尝试颜色重建。
- 红色地图：局部三个及以上通道接近饱和，真实颜色与纹理恢复空间很小。

镜头炫光、彩灯和强反射会改变高光重建质量。单通道未裁切不等于最终颜色一定正确。

## 暗部

- `deep_shadow_fraction`：贴近黑电平的像素比例。
- `shadow_fraction_below_5_percent`：低信号区域占比。
- `shadow_green_variation_proxy`：两个绿色 CFA 块信号在暗部的局部差异代理，范围为归一化 `0–1`，只用于发现潜在噪声风险。

暗部地图优先使用绿色 CFA 块信号，避免直接平均不同颜色 CFA；`<=0.02` 标为贴近黑电平，`0.02–0.12` 标为可尝试展开。单张照片没有暗场、平场和重复曝光，无法分离场景纹理、光子噪声、读出噪声与固定图样噪声。没有双绿色代理时，置信度降为 medium。

## 建议曝光

脚本以 P99.5 最高的 CFA 通道作为限制通道，把该通道推向约 0.90，得到基础 EV 建议，并限制在 `-1.5～+1.5 EV`。任一通道存在明显近裁切或裁切时，正向补偿会被限制。

该 EV 是四套候选的共同起点，不是拍摄现场的绝对正确曝光。白平衡与相机色彩矩阵仍可能改变最终高光。
