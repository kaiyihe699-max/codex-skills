# Prompt Patterns

## 场景提示词结构

```text
[主体锚点] + [场景动作] + [镜头与构图] + [光线与色板] +
[符号状态] + [与上一幕的视觉呼应] + [材质与风格] + [画幅]
```

## 变形写法

- 具体到回声：`同一个红色圆形符号从实物转为水面倒影，轮廓保持相似`
- 空间到物体：`墙上的圆形光斑逐渐拥有气球的体积感`
- 物体到天体：`红色光球缓慢扩大，最终与月亮的轮廓重合`
- 动作到构图：`人物的行走方向延续为雨水的斜向流线`

## 负面约束

只加入会破坏项目连续性的限制，例如：

```text
不要改变人物服装，不要加入额外主色，不要出现文字和 logo，
不要切换成明亮商业棚拍，不要让核心符号消失。
```

不要使用一长串泛化的审美词来代替视觉规则。可执行的形态、颜色、位置和动作比“高级、电影感、艺术感”更有用。
