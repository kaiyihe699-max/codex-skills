# 中文与中英混排光学校正

## 目录

1. 可见框与字体框
2. 按钮标签
3. 中英数字混排
4. 截图分析限制

## 1. 可见框与字体框

- 字体的 em box、行高盒和实际字形可见框不同。截图分析只能测量可见像素，不能声称取得了真实字体基线。
- 中文方块字的视觉中心受字形内部黑度影响；`一`、`器`、`我` 的像素重心差异明显。
- 文字垂直居中时同时检查字体 ascent/descent、行高和具体标签的可见框。
- 不要通过逐字移动修复普通 UI 标签；优先调整组件的 line-height、flex 对齐或整体 `translateY`。

## 2. 按钮标签

- 对短中文标签，在实际字体和字号下渲染后检查，不要只看设计工具的文本框。
- 圆角较大、上下留白较紧的按钮更容易暴露 1 px 的垂直偏差。
- 标签含句号、括号、百分号或货币符号时，单独查看标点造成的可见重心变化。

## 3. 中英数字混排

- 中英文不要只按 baseline 对齐，也要观察英文 cap height、x-height 与中文视觉框的关系。
- 数字金额、倒计时和百分比优先使用实际内容测试；不同数字组合的宽度和黑度会改变视觉平衡。
- 图标与中文并排时，图标中心通常接近中文视觉框中心，而不是文本行高盒中心。
- 字体 fallback 可能改变基线和字重。报告中注明实际渲染环境和字体来源。

## 4. 截图分析限制

- 普通截图不能可靠恢复字体名称、font metrics、tracking 或真实 baseline。
- 抗锯齿、缩放和压缩会改变字形边缘。优先分析 1x 原始截图或 2x/3x 无压缩导出。
- 只有拿到 HTML/CSS、SVG 或设计源文件时，才把像素建议转换成精确排版参数。
