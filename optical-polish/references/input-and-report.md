# 输入与报告说明

## 目录

1. 推荐输入
2. 背景与裁切
3. 输出文件
4. 置信度
5. 降级模式

## 1. 推荐输入

按可靠性从高到低选择：

1. 单个组件的 SVG 或无压缩 PNG。
2. 从设计工具导出的 2x/3x 组件裁切图。
3. 包含明确组件区域的页面截图，并使用 `--container` 指定范围。
4. 压缩 JPG 或复杂背景截图，仅用于初步诊断。

支持 PNG、JPG、JPEG、WebP 和 BMP。SVG 需要 CairoSVG；缺少时让用户导出 PNG，或在允许安装依赖的环境中安装 `requirements.txt`。

## 2. 背景与裁切

- 裁切范围应包含完整容器和少量必要留白，不要包含相邻组件。
- 纯色或近似纯色背景最可靠。渐变、照片和纹理背景会降低置信度。
- 透明图标应保留透明通道；脚本会直接使用 alpha 作为前景证据。
- 阴影和辉光会拉动视觉重心。优先提供关闭效果后的组件，也可在解释中把阴影当作独立视觉层。
- 自动背景估计使用主色聚类。估计错误时通过 `--background` 指定容器内部背景色。

## 3. 输出文件

- `analysis.json`：机器可读测量、置信度与建议。
- `annotated.png`：容器中心、视觉重心、可见边界和建议方向。
- `mask.png`：脚本认为属于前景内容的区域，用于检查分割是否正确。
- `corrected.png`：在平面图上模拟移动前景后的预览，不是最终源文件。
- `comparison.png`：原版与修正版并排对比。
- `report.html`：自包含报告，可直接用浏览器打开。

先检查 `mask.png`。如果遮罩把按钮背景、阴影或邻近元素识别为内容，则不要采用偏移建议。

## 4. 置信度

置信度综合以下因素：

- 背景主色是否稳定。
- 前景占容器的比例是否合理。
- 前景与背景是否有足够反差。
- 重心修正与负空间修正是否方向一致。
- 是否存在透明通道作为可靠分割依据。

`low` 不是设计质量结论，只表示当前素材不足以支持精确测量。

## 5. 降级模式

若 Agent 没有本地执行和文件输出工具：

1. 明确说明当前只能做视觉层面的定性分析。
2. 描述疑似偏移方向、可能原因和建议验证方式。
3. 不生成虚假的 JSON、像素偏移或文件链接。
4. 建议改用支持 Python 与文件输出的电脑端 Agent 运行完整模式。
