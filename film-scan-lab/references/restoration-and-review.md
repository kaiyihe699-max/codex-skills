# 除尘、划痕、颗粒与人工确认

## 红外通道

1. 将 IR 转成灰度浮点。
2. 用 ECC 对齐到可见光图。
3. 去除低频照明变化。
4. 对局部异常做稳健阈值和形态学清理。
5. 与可见光缺陷候选取并集，但保留来源字段。

传统银盐黑白片可能让 IR 同时响应真实影像。若 IR mask 覆盖面积过大、与可见光边缘高度重合或分布不稀疏，标记冲突并回退到可见光检测。

## 可见光缺陷检测

- 小灰尘：局部中值残差大、面积小、形状紧凑。
- 划痕：细长、方向连续、长宽比高。
- 真实边缘：在多个颜色通道和结构梯度中一致，不应自动修复。

所有阈值按图像短边缩放，不使用固定像素尺寸描述物理缺陷。

## 修复规则

- `conservative`：只修高置信度小灰尘。
- `normal`：扩大灰尘尺寸范围，仍不自动修大划痕。
- `off`：只生成 mask 和报告。
- 大划痕必须经过 `scratch-review.html` 选择，再用 `--review-decisions` 应用。

人工勾选只表示允许邻域修复，不代表恢复了胶片上已丢失的真实内容。

## 人工确认文件

`scratch-review.json`：

```json
{
  "image": "review-preview.jpg",
  "candidates": [
    {"id": "scratch-0001", "bbox": [x, y, w, h], "area": 120, "confidence": 0.82}
  ]
}
```

`scratch-review.html` 在浏览器中绘制候选框，允许逐项开关并下载：

```json
{"approved_ids": ["scratch-0001"]}
```

## 颗粒

- `preserve`：不做全局降噪，只修缺陷像素。
- `clean`：分离亮度和色彩噪声，做克制降噪。
- `rebuild`：先轻度清理，再根据低梯度中间调估计的高频能量重建密度相关颗粒。

记录颗粒强度、尺度、采样区域和随机种子。不要使用与分辨率无关的固定噪点覆盖。
