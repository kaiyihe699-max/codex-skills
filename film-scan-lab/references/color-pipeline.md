# 色彩与密度管线

## 1. 输入归一

1. 保留输入位深和 ICC。
2. 使用 capture profile 的黑白点、gamma、通道增益和 3x3 矩阵转换到浮点线性 RGB。
3. 相机翻拍 RAW 使用 rawpy 做无自动亮度的线性解码；扫描 TIFF 按配置解释 gamma。

输入 profile 不明确时使用 `generic-scanner-srgb`，并把配置可信度写为 `low`。

## 2. 胶片类型

- `color-negative`：片边通常有明显暖色片基，画面为负像。
- `bw-negative`：三个通道高度相关，画面为负像。
- `slide`：画面为正像，不做密度反相。

自动分类仅为启发式。片边不足、画面极端单色或扫描软件已做过反相时必须允许用户覆盖。

## 3. 片基与密度

对负片计算：

```text
T = clip((scan - black) / (white - black), eps, 1)
D = -log10(T)
D_scene = max(D - D_base, 0)
```

片基样本优先来自用户 ROI，其次来自外缘低梯度、高透射像素。同卷模式汇总所有画面的候选片基并使用稳健中位数。

不要在 gamma 编码 RGB 上直接减橙色，也不要独立自动拉满三个通道后声称色彩准确。

## 4. 胶片配置

配置字段：

- `channel_gamma`：三个染料层的密度响应近似。
- `matrix`：通道交叉校正近似。
- `toe`、`shoulder`：正片映射的趾肩。
- `neutral_contrast`：中性解释。
- `print_contrast`、`print_warmth`、`print_saturation`：印相解释。

内置配置是稳健起点，不是厂商官方光谱模型。用户提供色卡扫描或设备配置时优先使用用户配置。

## 5. HDR 扫描

多次扫描必须来自同一胶片帧。流程：

1. 转成 8-bit 灰度预览，使用 ECC 对齐平移/轻微仿射。
2. 在非饱和像素上估计相对曝光比例。
3. 转换为线性透射率并除以曝光比例。
4. 使用中间值权重合并；接近黑白端的样本权重降低。
5. 输出对齐变换、曝光比例和每像素有效样本数。

曝光比例无法稳定估计时回退到曝光融合，并在报告中标注 `relative`，不要声称绝对 HDR 辐射度。

## 6. 输出色彩

- TIFF 使用 uint16 RGB，并嵌入 sRGB ICC。
- JPEG 使用 8-bit sRGB 与相同 ICC。
- `00-source-master.tiff` 仅做格式归一，不反相、不修复。
- 档案正片保留较宽百分位范围；中性和印相版允许显示参考曲线。

只有使用经过验证的扫描仪 ICC、翻拍相机配置或画面内色卡时，才报告色差或“准确还原”。
