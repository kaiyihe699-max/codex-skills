# 映射系统

## 目标

映射必须满足三个条件：可复现、可解释、具有最低限度的音乐性。不要把随机选择包装成“智能感知”。

## 图像到音乐

| 图像信息 | 音乐参数 | 说明 |
| --- | --- | --- |
| 扫描位置 | 时间 | 横向扫描使用 x；径向扫描使用角度 |
| 纵向或半径分带 | 音高 | 先映射连续音域，再量化到所选音阶 |
| 色相 | 音色族 | 红橙偏 warm，黄绿偏 grain，青蓝偏 glass，紫偏 pulse |
| 饱和度 | 力度 | 与纹理、亮度共同计算，避免暗部完全静音 |
| 亮度 | 时值与音区感 | 明亮且平滑的区域通常产生更长的音 |
| 边缘与纹理 | 密度 | 只提高候选显著性，不逐像素触发 |
| 局部对比 | 起音与时值 | 对比低的区域倾向延音，对比高的区域倾向短音 |

## 扫描路径

- `horizontal`：最容易阅读。适合风景、街拍、海报、横向动线和一般测试。
- `radial`：从画面上方开始顺时针扫描，半径映射音高。适合中心主体、唱片、花朵、建筑穹顶和放射构图。

扫描路径会改变时间结构，因此切换扫描路径属于重新作曲，不是简单换一种预览。

## 音阶

- `pentatonic`：默认；容错高，适合公开展示和第一次生成。
- `major`：明亮、稳定，适合高亮度和产品视觉。
- `minor`：适合低照度、戏剧化和夜景，但不要把“暗图等于悲伤”作为固定判断。
- `dorian`：介于小调和开放感之间，适合设计实验。
- `chromatic`：保留更多位置差异，也最容易产生紧张与杂乱。仅在用户明确要求实验性结果时使用。

## 预设

预设只是参数起点：

- `prism`：D 五声音阶，横向扫描，中等密度，平衡四色音色。
- `grain`：A Dorian，横向扫描，高密度、短延音，突出颗粒与边缘。
- `orbit`：E 小调，径向扫描，较慢速度和较长延音。

## 复现

完整复现至少需要：源图、预设、根音、音阶、BPM、小节数、分带数、每小节步数、密度、平滑度和随机种子。全部写入 `mapping.json`。当前版本的随机种子只影响合成器中的细微噪声，不改变 MIDI 音符结构。
